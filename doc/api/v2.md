# API v2 — the broker

Mounted at `/api/v2`, documented live with Swagger at `/doc/` (and
`/swagger.json`). The endpoints come with roadmap step 6 (`doc/ROADMAP.md`).

## Health

`GET /api/v2/health` → `200 {"status": "ok", "database": true, "version": …}`,
or `503` with `"status": "degraded"` when Valkey is unreachable.

## Errors

Every error under `/api/` (and for any client whose `Accept` header prefers
`application/json`) is JSON:

```json
{"status": 404, "error": "Not Found", "message": "The requested URL was not found on the server…"}
```

Other requests get the error page (`templates/error.html`): code, title,
message, a link to the home page and to the API documentation. 404, 405 and
500 have their own wording (`ERROR_MESSAGES` in `website/web/__init__.py`);
an unhandled exception is logged and answered as a 500.
